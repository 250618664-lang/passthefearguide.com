# Pass the Fear Guide Hub

An unofficial, source-aware English guide hub for [Pass the Fear on Steam](https://store.steampowered.com/app/3561220/Pass_the_Fear).

Built with Astro (static output, no database, no analytics, no ads in this commit).

## Install

```bash
npm ci
```

## Type-check

```bash
npm run check
```

## Build

```bash
npm run build
```

## Validate

```bash
npm run validate
```

## Notes

This site is **not affiliated with** or **not endorsed by** the developers of Pass the Fear. All facts are traced to registered source IDs in the page source. This site does not use official game images or media.
